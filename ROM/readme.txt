Это файл для прошивки в SPI Flash, который является дампом всей памяти адресного пространства процессора, включая ОЗУ и ПЗУ. 
Прошивка "Монитора" начинается с адреса F800h.
ОЗУ 32Кб начинается с адреса 0000h.
В этот дамп можно добавлять программы (файлы с разрешением *.rk), просто вставляя их содержимое в hex редакторе. Адрес начала программы в ОЗУ - это первые два байта *.rk файла, адрес конца программы - 3,4 байты (первые 4 байта вставлять в дамп не надо!). Скопированную программу можно запустить из "Монитора" директивой "G" с адресом начала программы в ОЗУ, например "G 09A0".
