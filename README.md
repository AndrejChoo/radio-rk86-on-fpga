# radio-rk86-on-fpga
Реализация советского радиолюбительского компьютера Радио-86РК на FPGA

В качестве центрального процессора использована HDL модель КР580ВМ80А от vslav: https://github.com/1801BM1/vm80a
Частота тактирования процессора близка к оригинальной 1.78MHz (для получения данной частоты используется модуль PLL, который также синтезирует частоту и для модуля HDMI 50Mhz и 250Mhz).

Видео выводится по HDMI в разрешении 800х600 (разрешение РК 768х400 - 64х25 знакомест 6х8 точек с удвоением плюс бордюр) в монохромном режиме.
В качестве видеоадаптера реализован упрощённый функциональный аналог БИС кр580вг75, так как в сам РК не использует многих функций этой микросхемы.
Прошивка знакогенератора стандартная, она хранится в сгенерированной блочной памяти на 1Кб.
Видеопамять 4Кб также реализована на блочной памяти FPGA (двухпортовая RAM), процессор записывает в неё данные параллельно с основным ОЗУ. Благодаря этому не требуется торможения процессора, как происходит в оригинальном РК при работе контроллера DMA.

В качестве ОЗУ и ПЗУ используются микросхема SRAM (достаточно любой микросхемы SRAM с 8-битной шиной данных и минимальным объёмом 64Кб. 
Прошивка монитора хранятся в микросхеме SPI Flash 25-й серии, при запуске или после сброса данные из флешки переписываются в SRAM и далее считываются уже оттуда. Также в память ОЗУ я сразу записал игру "Питон" для демонстрации (его можно запустить командой "G 9A0" из монитора). 

Прошивка "Монитора" используется для версии компьютера с объёмом ОЗУ 32Кб. 

Звук выводится на обычный биппер.

В качестве клавиатуры используется USB клавиатура, которая подключается через переходник на микроконтроллере stm32f411ceu ("Black pill").

Проект написан и отлажен на FPGA Altera Cyclone 10LP. В проекте имеются специфичные для Altera блоки: PLL, блочная память, ALTDDIO для модуля HDMI.
Проект занимает менее 1500 логических ячеек и 34816 бит блочной памяти, поэтому поместится и в более дешёвые FPGA, например, Cyclone 4E EP4C6.
